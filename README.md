# Seoul ID

Editorial web archive for Ryu Haechan’s industrial design work, published by Drei Stack.

The desktop layout treats the viewport as a restrained double-page spread. A soft central gutter suggests the depth of an open book without paper textures or flipbook effects. Below 900 px, the layout becomes a single-page mobile sequence and removes the gutter.

## Routes

- `/` — landing spread and product index
- `/1` — first product detail spread with an independent image sequence

## Development

Requires Node.js 22.13 or newer.

```bash
npm ci
npm run dev
```

Run `npm run build` for the production build and artifact validation.
